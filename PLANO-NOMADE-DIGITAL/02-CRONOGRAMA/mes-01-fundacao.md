> **Como usar este arquivo:** abra só o dia de hoje. Faça os blocos na ordem. No fim, preencha a linha do dia em `08-REVISOES/acompanhamento-180-dias.csv` (ou no arquivo PLANO-NOMADE-180.html). Domingo é revisão + descanso — não é dia de recuperar conteúdo atrasado, é dia de decidir o que cortar.

**Material recomendado:** Treinamento oficial gratuito da Blackmagic (vídeos "Editing" em blackmagicdesign.com/products/davinciresolve/training) · YouTube: busque "Casey Faris DaVinci Resolve beginner tutorial" (em inglês, com legenda em inglês)

| Tempo | Bloco | Tarefa exata |

Pronúncia (10 min): YouGlish com 3 palavras difíceis. |
| 40 min | Conceito | Assista ao tutorial (1.25x) e anote: para que serve cada página (Media, Cut, Edit, Fusion, Color, Fairlight, Deliver) e os atalhos B, A, I, O, Ctrl/Cmd+B, Shift+Z. |
| 80 min | Prática | Briefing fictício "North Brew — café gelado em lata, 20% OFF esta semana". Monte 15 s vertical: gancho (0–2 s), benefício (2–8 s), oferta (8–12 s), CTA (12–15 s), com Text+ e música. |
| 30 min | Registro | Exporte, assista no celular, anote 3 problemas (ritmo, texto, áudio) na aba "Diário de aprendizado". |

**Passo a passo:**

1. Configure a timeline vertical: na Media Pool, botão direito → Timelines → Create New Timeline → desmarque "Use Project Settings" → Format → 1080 x 1920 (custom), 30 fps.
2. Se a reprodução travar: botão direito nos clipes → Generate Optimized Media (ou Proxy). Playback → Use Optimized Media If Available.
3. Baixe 6–8 clipes do Pexels: café sendo servido, gelo caindo, pessoa bebendo na rua, close de lata/garrafa, escritório. Música: YouTube Audio Library (filtro "sem atribuição exigida").
4. Estrutura: 0–2 s imagem mais forte + texto "Iced coffee. 2 seconds." · 2–8 s 3 cortes rápidos com benefícios (1 texto por corte) · 8–12 s "20% OFF this week" · 12–15 s "Order now" + logo fictício (texto).
5. Texto: Effects → Titles → Text+. Fonte bold sem serifa, tamanho grande, centralizado no meio da tela (não no rodapé — a interface do Reels cobre).
6. Música: arraste para a trilha A1, corte para terminar junto com o vídeo, aplique fade de 0,5 s no fim (arraste a alça no canto do clipe).
7. Exporte: Deliver → Custom → H.264, 1080x1920, qualidade "Automatic/Best". Nome: D02_northbrew_v1.mp4. Mande para o seu celular e assista como se estivesse no Instagram.

- **Exercício prático:** Anúncio vertical de 15 s com estrutura gancho-benefício-oferta-CTA.
- **Entrega concreta:** D02_northbrew_v1.mp4 (1080x1920, 15 s) + 3 problemas anotados.
